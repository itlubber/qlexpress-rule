# 模型在线测试就绪流程实施计划

## 目标

让业务人员在执行模型前能够确认输入字段与样例参数的来源，加载异常时明确知道当前页面是否使用了降级数据；重复打开或重复执行时，旧请求不得覆盖当前测试状态；保存测试参数时准确表达“创建审批草稿、审批后生效”。

## 实施范围

1. 将测试弹窗初始化状态细分为加载中、就绪、降级可用和加载失败，并展示输入字段数量、参数来源与非阻断告警。
2. 最新测试 Schema 不可用时允许回退到模型输入字段，模型配置样例不可用时允许回退到 Schema 样例，但必须把原因展示给用户并提供重新加载入口。
3. 已保存参数、上传样例、来源未标记的兼容配置、Schema 样例和字段默认值按明确优先级初始化；来源随版本化模型配置持久化，界面标注实际采用的来源。
4. 打开弹窗、关闭弹窗和执行测试均增加请求序号保护，只允许当前弹窗最后一次请求更新字段、结果和加载状态。
5. 不支持在线执行的模型格式禁用执行按钮；执行过程显示明确状态，失败后保留参数供修正重试。
6. 保存测试参数增加提交中状态，并将成功提示改为“已创建审批草稿”，随后进入审批详情，避免把待审批误认为已生效。

## 验收标准

- 正常加载时可看到输入字段数量和参数来源。
- Schema 或模型配置样例解析失败时，页面仍可使用可靠的回退数据，同时展示具体告警和重新加载入口。
- 同一模型重复打开测试弹窗、关闭后重新打开、连续执行时，迟到响应不会覆盖当前字段或结果。
- 不支持 PMML/ONNX 在线执行的格式无法点击执行。
- 保存按钮在提交期间不可重复点击；成功后提示待审批并跳转对应审批详情。
- 单元测试、ESLint、构建、Playwright、真实前后端浏览器验收和后端回归全部通过。
